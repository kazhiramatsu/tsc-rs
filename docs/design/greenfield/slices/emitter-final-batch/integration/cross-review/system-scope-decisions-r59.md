# System scope design and observed follow-ups

Opus58 corrected the earlier top-level-function rule: only syntactically exported hoisted function declarations keep the module lexical environment; ordinary declarations get function environments. The implementation follows this distinction before removing export modifiers. New nested temps use TargetBinding identities directly, bypassing the module spelling map, and the shared context lexical environment. Existing module string names and order remain intact. Parameter defaults and binding patterns lower only when a parameter initializer hoists a temp and the target retains native parameters. Directive/custom hoist insertion follows mergeLexicalEnvironment. Concise arrow conversion preserves both return and block ranges, unlike the existing ES2021 helper's omission; ES2021 itself is untouched.

The complete TypeScript command corpus expanded270 to392 with exported/nonexported/default functions, computed methods/getters, static blocks, class fields, captured/local names, nested/sibling scopes, parameter binding patterns, discarded updates, nullish lowering, and destructuring assignments. All270 previous observations remain byte-for-byte unchanged. Every new observation is repeated twice. The void expression control disproves the no-temp expectation in Opus58: () => void x++ does allocate a temp, while expression statements and for initializer/incrementor fields discard the value. The implementation retains that distinction, also propagating discarded status through parentheses and PartiallyEmittedExpression.

The immutable f0 r55 native run independently exposed outstanding differences, not accepted waivers: namespace-import publication acquired unwanted source maps from the new import-name range; System using re-created its variable list without the original list range; and importHelpers was hoisted before preceding CustomPrologue vars instead of after copyPrologue visits them. These fixes will preserve whole command expectations rather than alter fixtures. Scope and shared-destructuring design are undergoing Opus59 review before native compilation.
