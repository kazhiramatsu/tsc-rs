**G3 assessment: all four proposals hold structurally, with these corrections and bounds. Probes are against vendored 6.0.3.**

**1. Reparsed runs: sound as a context fact, with the invariants below.** The Rust reparse (parser.rs:9598-9666) records `Reparsed{start = run's first old statement pos, end = scanner full start at loop exit}`, re-parses under `context_flags | AWAIT_CONTEXT`, and `finish_node` (9929) stamps every created node with the context flags. tsc probe confirms root statements in the run carry `AwaitContext` and those outside do not. Loop exit is either `statement.end == non_await_pos` or EOF, so the last reparsed statement's end equals `end`; the first's pos equals `start` by `reset_token_state`. A no-progress skip inside the run is already recorded as `TopLevelAwaitReparse` and stays refused. Constraints: (a) `start < end`, both scalar boundaries; (b) exactly one contiguous root-statement run with `first.pos == start`, `last.end == end`, every statement in it carrying `AWAIT_CONTEXT`, and the adjacent statements outside it not carrying it; (c) runs pairwise disjoint; (d) `!is_declaration_file && is_external_module` (the invocation condition at 10219-10223, redundant but cheap to assert); (e) no other action kind changes meaning. With that, `Reparsed` stops being a blanket refusal and every event inside is proven by the existing rules. No await node needs to exist; the flag on the statements is the witness. Also note the reparse re-derives events for the run, so retained-index coverage already checks them.

**2. Missing-expression slots: use creation-site provenance for the decorator branch.** tsc emit shapes (experimentalDecorators, ESNext):

```
await (1, );                         comma right, zero-width at Binary.end
await , string > (1);                assertion operand (item 3)
__decorate([ (await ) ], C1)         @(await)
__decorate([ (x) ], C2)              @await(x): call with empty callee prints as (x)
__decorate([\n], C3)                 @await: empty element, no blank line
__param(0, )                         parameter decorator
```

`parse_decorator_expression` (parser.rs:4738-4747) consumes `await` with `next_token()` after creating the missing head; that is a token loss with only the diagnostic as witness. Record it as `TokenSkipped { site: DecoratorAwait }` before the `next_token()`; then G3 owns it structurally: exactly one reachable Decorator whose expression's left-hand chain (Call/PropertyAccess/ElementAccess rest) heads in a zero-width Identifier at `skip.start == missing.position == full_start`, with the retained current-token report spanning exactly the skip (`start + length == skip.end`). That covers the Decorator-direct and Call-callee cases without `@`-offset arithmetic or text checks. Comma slot: zero-width Identifier is `right` of a BinaryExpression with `CommaToken`, `id.pos == id.end == Binary.end`, retained current-token report at that position, and the enclosing node consumed its closer normally (`Paren.end > Binary.end`), so it does not collide with the G2 closer tie. Keep other operators refused. Neighbour behavior: `@)` in a module (probe) parses as `MissingDeclaration[Decorator[Identifier[12,12]]]` plus a statement-level `)` skip; under the Decorator slot it becomes admitted and tsc emits only `class D {}`; add it as a positive control or exclude it by requiring the `DecoratorAwait` site on the head, which the provenance route does for free. `@await class C3 {}` in a non-module is clean (`await` is an identifier, emits `__decorate([await], C3)`): a negative-space control.

**3. Suppressed assertion operand: pair it to an assertion-closer tie.** Probe: `TypeAssertionExpression[16,24]` with `Identifier[24,24]`, one diagnostic `24+1:1005` (`>` expected), the `Expression expected` at the same start deduped. Constraints: retained current-token report-only E; exactly one reachable TypeAssertion T with `T.end == E.full_start`, `T.type.end == T.end` (no `>` consumed), `T.expression` zero-width at `T.end`; exactly one suppressed missing-node event at `E.start` with `missing.position == T.end`, kind Identifier; consume both and insert the position into `missing_positions` so the existing TypeAssertion-parent walk accepts it. This is the only place a suppressed missing-node event is admitted; the general refusal stays.

**4. HeritageClause types: tiling proof, one array kind, non-empty.** Probe for the module case: `HeritageClause[18,40]`, `ExpressionWithTypeArguments[33,39]`, diagnostics `27+5:1109`, `32+1:1109`, `39+1:1005`, emit `class C extends string {`. Proof: exactly one innermost reachable `HeritageClause.types` array containing all its skips; merge children and skips in position order and walk a cursor from `array.pos`: a skip requires its single retained current-token report's `full_start == cursor` and moves to `skip.end`; a child requires `child.pos == cursor` and moves to `child.end`; finish at `array.end`; all skips `ListAbort`; suppressed same-start reports ride along. Require at least one child: `class C extends await {}` in a module yields an empty clause and tsc emits `class C extends  {` (invalid JS); keep that a refused neighbour until measured. Do not generalize the cursor rule onto the frozen G2 arrays; G2 keeps its preceding-element rule for census projection.

**Semantic dangers beyond blank leaves (all printer-side, need controls):** list formatting with an empty element (`[\n]` without a blank line, `__param(0, )` trailing space, `(1, )`), a CallExpression with an empty callee printing as `(args)`, `(await )` inside the decorator array, `await ` followed directly by `,`, and the esDecorators path: run `@await class C3 {}` with `experimentalDecorators: false` too, since `__esDecorate` is a different transform. Implements clauses erase entirely, so a skip-owned `implements` gap emits nothing; include one.
