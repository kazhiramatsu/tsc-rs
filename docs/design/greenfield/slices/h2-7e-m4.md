# H2.7e m-4: declaration-map getter and forced-call semantics

This packet admits non-bundle declaration-map getters and forced declarations
through the existing `DeclarationSession`. Each call uses the same initialized
checker and the existing per-source getter diagnostic cache. A forced call
still borrows a fresh resolver view and performs declaration transformation
and map recording for that call; it does not reuse ordinary output or cached
map artifacts. Ordinary targeted emit remains H2.8d, ordinary noEmit remains
H2.9, and outFile remains the separate bundle boundary.

The frozen `declaration-map-apis.json` has 54 sequences. This bounded comparator
covers their 77 getter and 92 forced calls twice, including repeated whole and
target getters, diagnostic errors, empty and declaration-only Programs,
JavaScript/JSON inputs, disabled declaration options, forced gate bypass,
source-map allocation, sink onError/skip feedback, and direct callback throws.
It compares Program source order and ordered libraries, complete call output,
raw map JSON and source association, callback
order/bytes/BOM/metadata before and after feedback, materialized write indices,
diagnostics, exception/result presence, and emittedFiles/sourceMaps presence.
Resolver borrow counts are compared separately; TypeScript's source request
trace is not represented as a Rust source identity trace. Empty Programs retain
the established zero-Rust-borrow versus one-TS-request adapter.

The 21 ordinary command calls and final same-checker Program diagnostic
snapshots are explicitly not asserted here. Mixed sequences skip the ordinary
call, so this is primary getter/forced-call coverage, not a claim of complete
54-sequence equivalence. Earlier ordinary sink/gate comparisons remain in m-2;
those fresh Program checks do not substitute for later same-session command
integration. No reference input, expected diagnostic, or unsupported owner is
rewritten into a success row.

For declarationMap true with declarations disabled, TypeScript 6.0.3 may print
a forced declaration and then throw at `getSourceMappingURL` because no map
path was allocated. Rust returns the narrow
`EmitContractViolation::DeclarationMapPathMissing` at that same boundary.
The comparator maps that typed contract error to the reference Debug Failure
exception, preserving a null emit result. This is distinct from `OutputSink`
returning an I/O error (TS5033 with continuation) or a callback unwinding (the
controlled throw with no result). Forced output now dispatches map then text
for each source before preparing the next, preserving an earlier JSON write
if a later source fails at the missing-map-path boundary.

Map recording is enabled from declarationMap and source eligibility, not just
map-path presence. JSON retains the TS6 no-generator branch, including its
counterintuitive forced emittedFiles map entry when no actual map write exists.
A map-disabled declaration never acquires map-lane host inputs. SourceMaps
allocation still follows sourceMap, inlineSourceMap or effective declarationMap;
empty allocation and absent allocation remain separate.

The fixed TypeScript 6.0.3 sources are `getAreDeclarationMapsEnabled`
(`_tsc.js:18169`), `emitFiles`/`emitDeclarationFileOrBundle`
(`_tsc.js:116532,116640-116715`) and print/map URL handling
(`_tsc.js:116744-116804`). The pinned native reference
`1f70213d4922b434345f639b441681e470c7cfc1` was also reviewed at
`tsc/internal/compiler/emitter.go:222-402` and `program.go:1799-1870`.
Its forced declaration-map path override and write/list behavior differ from
TS6; this packet retains the frozen TS6 exception and list expectations.

No global activity/profile/adoption marker, schema, or closure membership is
changed by this semantic packet. Bundle declaration maps, complete same-state
ordinary/reporting integration, and original transpile references remain
separate work.

Validation uses the worktree-exclusive `target/h2-7e-api-check` with one Cargo
job and test thread at background priority. The new comparator passes all
338 primary calls; its final run, including source/library order assertions,
takes 64.29 seconds. The seven existing ordinary/direct-map integration tests
pass in 91.80 seconds. All 19 retained H2.7c getter sequences pass, and all
37 retained forced sequences pass across the TypeScript, JSON and empty
Program comparators. The frozen API observer's complete 54 plus two adjacent
reference sequences also pass repeated freshness checks without fixture edits.
Clippy passes with warnings denied for the Program, emitter, checker and
compiler libraries and both dedicated declaration-map integration tests.
Formatting and diff whitespace checks pass. The shared `DeclarationSession`
implementation itself did not need a change in this packet: its cache and
resolver borrowing already supply the observed getter/forced-call semantics.
