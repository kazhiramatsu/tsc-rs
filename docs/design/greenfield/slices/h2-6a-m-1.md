Call graph (read at this base): `getRelativePathToDirectoryOrUrl` →
`getPathComponentsRelativeTo(resolvePath(cwd, dir), resolvePath(cwd, path),
equateStringsCaseSensitive, getCanonicalFileName)`. `resolvePath` =
`normalizePath(combinePaths(…))`, and `normalizePath` runs the
`relativePathSegmentRegExp`-gated `simpleNormalizePath` fast path with the
`getNormalizedAbsolutePath` fallback (5493-5567) plus trailing-separator
preservation — the full closure is pinned above (review finding 1). The
relative-to worker reduces both component lists
(`reducePathComponents(getPathComponents(…))`), canonicalizes EVERY
compared component — including component 0 — through
`getCanonicalFileName` (5699-5700), then applies the per-index comparer:
`equateStringsCaseInsensitive` (`toUpperCase` equality) for component 0
and the passed case-sensitive comparer afterwards; it returns the
absolute `to` components on zero shared prefix, else
`["", ".."×k, rest…]`; the URL arm replaces a rooted first component with
`file://`+root (root starting with `/`) or `file:///`+root;
`getPathFromPathComponents` joins with the root's trailing separator
ensured. `combinePaths` restarts at any rooted segment;
`reducePathComponents` drops empty/`.` segments, pops on `..` when the
last kept segment is not itself `..`, DROPS a `..` outright at depth 1
under a truthy (absolute) root, and keeps leading `..` only under an
empty (relative) root (5462-5469); `getEncodedRootLength` covers
POSIX/backslash and UNC (`//server/`) roots, `X:`/`X:/` volumes, and
`scheme://authority/` URLs (file-URL volume arm) with the `~`-negative
URL encoding that `getRootLength` strips. The upstream canonicalizer
behind `host.getCanonicalFileName` is
`createGetCanonicalFileName(useCaseSensitiveFileNames)` = identity or
`toFileNameLowerCase` (873-876): a `fileNameLowerCaseRegExp`-guarded
lowercase that preserves `\u0130`/`\u0131`/`\u00DF` and lowercases only
matched runs.

Port-equivalence argument for `resolvePath` (recorded, review finding 1):
the resolved strings feed only `getPathComponentsRelativeTo`, which
immediately re-splits and re-reduces them; `reduce ∘ components` is
idempotent over `normalizePath`'s output and equal to
`reduce ∘ components` over the un-normalized combined string (both drop
empty/`.` segments identically; both clamp `..` at an absolute root —
`getNormalizedAbsolutePath` 5544-5552 vs `reducePathComponents`
5462-5469 — and both preserve leading `..` for relative inputs). The Rust
port therefore computes the REDUCED COMPONENT LISTS of
`combine_paths(cwd, …)` directly and never materializes the normalized
string; `normalize_path`'s string form is NOT ported in this rung (its
first string-level consumer is m-3's `getSourceMapDirectory` lane).

## 8. Frozen witnesses and suite

The W-H2.6A artifact is the sole byte authority; no expected output is
authored by hand. Suite `crates/emitter/tests/unit/source_map/tests.rs`:

1. **Witness replays (the teeth):** for every parity-lane case with ≥1
   `.js.map` write (measured: 24 cases) — parse the frozen
   `source_map_json`; decode `mappings` with a test-only VLQ decoder
   (round-trip instrument local to the suite); construct the generator
   NOT with the map's own `file` field but from the CASE inputs exactly
   as m-3 will: `file` = the basename of the `.js` write path and
   `sources_directory_path` = its directory — both derived in the TEST
   with plain string suffix/prefix operations (the inputs are normalized
   VFS paths; `getBaseFileName`/`getDirectoryPath` are m-3's ports, not
   this module's — review finding 1), `source_root` = `""`,
   `sources_directory_path` = directory of the js write path,
   `current_directory` = `/project`, case-sensitive; `add_source` each
   `input_source_file_names` entry in order; replay the decoded segments
   through `add_mapping` in order; assert `to_json_string()` byte-equals
   the frozen `source_map_json` AND the `.js.map` write's decoded callback
   bytes. This proves the VLQ encoder, the dedupe/commit machine (decoded
   segments include every committed mapping — recommitting them must
   reproduce the identical string), the relativizer (`../src/nested/…`
   climb, bare basenames, the space name), and the serializer at once.
   The `boundary-controls--control-sourceroot` case replays with
   `source_root = "src/"` and `sources_directory_path` = the common
   source directory (`/project`), proving the 6b-facing constructor
   parameters carry exactly.
2. **Dedup/backtracking contracts:** identical-position re-adds collapse
   into one segment; a backtracking source position (same source index,
   earlier line/character) forces a commit; a line advance emits `;`
   runs and resets the character base while `,` separates only committed
   same-line successors; a source-less mapping after a sourced one at a
   new position commits the sourced one intact (asserted through the
   emitted `mappings` string only — no state peeking).
3. **VLQ vectors:** 0/±1/±2/15/16/±31/±32/large multi-digit continuation
   values, asserted against independently computed spec encodings in the
   test (algorithm-level vectors, not tsc-observable bytes).
4. **Escaper contracts:** quote/backslash/backspace/formfeed/newline/
   carriage-return/tab/other-C0 (lowercase four-digit hex), plus raw
   passthrough for DEL, U+2028/U+2029, and non-ASCII — asserted against
   the V8-verified encodings (`serde_json::to_string` cross-check allowed
   as a second witness in the test).
5. **Serialization-shape contracts:** key order; `sourcesContent`
   omitted when `None`/emitted (with `null` holes) when set via
   `set_source_content`; `names` always `[]` in every replay.
6. **Absence note:** a module doc-comment table names
   `appendSourceMap`/`decodeMappings`/`addName` as dead-in-build with
   their h2-6a.md §4.2 owners; the suite asserts the public surface via
   compile-time use only (no reflection needed — the doc table is the
   record, the review checks it).
