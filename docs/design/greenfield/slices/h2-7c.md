supplies the same leading/trailing ranges. It needs internal visibility,

the existing original-node chain. Ordinary declarations inspect any leading

comments also carry the literal case-sensitive `@internal` substring.

The implementation boundary follows `_tsc.js:124946–124953` for option validation,
`125641–125668` for the whole-program noEmitOnError gate and `114249–114263` for
the diagnostic-only declaration transform. Existing options, syntax, global and
semantic diagnostics take precedence; only an empty collection triggers the
declaration diagnostic pass. No JS transformation, printing or writing may occur
before a blocking result. Ordinary emission still blocks individual declaration
members while permitting JS and unaffected declarations. A missing declaration
path sets emitSkipped for actual source units under emitDeclarationOnly, but an
all-d.ts program has no unit and retains emitSkipped=false unless noEmitOnError
blocks its option diagnostic. Public targeted/forced getter routes remain later
work; this packet adds only the production gate needed here.
