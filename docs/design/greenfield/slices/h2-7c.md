# H2.7c — declaration diagnostics and options

Status: first bounded implementation locally validated, 2026-09-07. Trusted base for
this work is the H2.7b close `ff57ee55`; runtime closure is PR #509. The
user's instruction to resume H2 and continue the lightweight implementation
flow authorizes this packet. This does not activate the whole H2.7c band.

The era covers stripInternal, declarationDir, isolatedDeclarations and
getDeclarationDiagnostics/forced declaration semantics. Ordinary targeted
Program.emit and emit-only API routing retain the H2.8d owner. Bundles,
declaration maps, the general output matrix and transpile retain their
separate owners. H2.7b's frozen 1,557/36 profile is unchanged.

The first cause group ports `shouldStripInternal` and
`isInternalDeclaration` (`_tsc.js:115760–115762`, `12601–12635`) through the
existing declaration visitor call sites: statements, subtrees, enum members,
parameter properties and binding elements. The option is currently refused
in `execute.rs` and the declaration predicate in `ensure.rs`; both boundaries
must change together. The comment-range scanner already used by the printer
supplies the same leading/trailing ranges. It needs internal visibility,
with no change to its scan algorithm. Parse-tree provenance is recovered via
the existing original-node chain. Ordinary declarations inspect any leading
comment, whereas parameter properties inspect the last combined comment
range, including inline comments after the previous parameter's comma.
JSDoc parsing alone is insufficient: line comments and ordinary block
comments also carry the literal case-sensitive `@internal` substring.

Frozen observations: `scripts/observe-strip-internal.mjs` captures two runs
of 15 windows: the complete official `stripInternal1` and
`declarationEmitWorkWithInlineComments` sources, plus adjacent declaration
comment ownership, each with enabled/disabled/declaration-only/removeComments/
JS-only options. Source hashes and full output/callback/result observations
are in `crates/compiler/tests/fixtures/strip-internal.json`. Expected bytes
come exclusively from the pinned compiler. Rust tests use the production
ProgramSession and load exact options directly, avoiding the existing harness
floor that intentionally drops stripInternal. Existing profiles keep that
floor and their original case membership.
