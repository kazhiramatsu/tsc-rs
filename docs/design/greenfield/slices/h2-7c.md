## Eleventh packet: forced declaration-only emission

`ProgramSession::emit_forced_declarations` and the scoped session method expose
whole-Program or targeted force=true/emitOnly=true execution. Each nonempty
Program call borrows the same initialized checker without scheduling source
checking. A hidden harness entry uses the existing Eager driver to observe an
emit after semantic diagnostics on that same checker. Repeated declaration
getters continue using their independent cache.

The Program retains forced source eligibility separately from ordinary JSON
path eligibility. External-library ownership and declaration inputs still
exclude sources. The internal `noEmitForJsFiles` option is represented only on
the Program API and also excludes JSON, whose actual parser flags include
JavaScriptFile. Config and existing harness option projections retain None.
Ordinary whole-Program preflight computes blocked paths with the real options;
a plan-owned adapter then supplies forced declaration-only output units.
Forcing a declaration path does not add a new collision to that blocked set.

The common-directory projection now uses that same ordinary source-selection
worker. An additional enabled/disabled noEmitForJsFiles pair reproduced an
excluded JS source incorrectly retaining a parent directory in the declaration
output path: types/a/source.d.ts instead of types/source.d.ts. Reusing ordinary
selection fixes the path; both complete observations match twice. The original
35 forced and 35 reference observations remain unchanged when adding this pair.

The shared declaration worker includes JSON and collects linked aliases when
forced. It preserves diagnostics and the actual declBlocked/emitSkipped value,
then prints even if blocking occurred. `handleNoEmitOptions` is bypassed, so
semantic/syntax errors and noEmitOnError do not independently stop this forced
route. The ordinary and forced executors share the existing artifact write/error
dispatch. Declaring a forced root uses its forced path while reference targets
still use ordinary paths. No JavaScript transform or artifact is constructed.

The JSON parser previously omitted JavaScriptFile/JsonFile context flags. It
now stamps the upstream flags on root, descendants and EOF, allowing the
existing JS declaration serializer to handle JSON. The existing parser oracle
pins check these flags. They exposed a second omission: finishNode masked out
JsonFile because it is outside NodeFlags.ContextFlags. That mask now follows
upstream finishNode and propagates every current context flag, including EOF.
The declaration transformer already marks its updated
root as a declaration file; the printer now sends that generated root through
normal declaration printing instead of the raw JSON value worker. This supports
object exports, nested namespaces, arrays, strings and null without a second
JSON-specific declaration serializer.

Source-less Programs preserve the established Rust unavailable-resolver path.
ProgramSnapshot and ProgramBinder still reject empty checker programs; the
compiler creates no synthetic source or checker. Public emit results must match
