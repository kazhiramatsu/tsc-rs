## 6. Probe schema 2 — event model and invariants

Same generator file, same frozen 94-case families + S2 (§8).

1. **Event model.** Every event is
   `{site_id, event_seq, call_id, depth, args}`:
   `event_seq` = per-case monotone integer over ALL events;
   `call_id` = stable per probed call, assigned at entry, shared by
   the paired `.entry`/`.result` events (site_id keeps its
   `.entry`/`.result`/site-specific suffix); `depth` = probed-call
   nesting depth at emission. Pairing = same call_id; LIFO of
   call_ids verified at mint and at replay (round-3 F3 consistency
   fix). Non-call sites (writers, seeds, markers) carry call_id=-1.
2. **Per-case fileTable (ONE definition).** The artifact records,
   per case, an ordered fileTable; row = `[class, key]` with class
   `"src"` (key = manifest input index) or `"lib"` (key = lib file
   basename). Every node reference's fileTag indexes THIS table;
   fileTag -1 = no file (synthetic without source projection).
3. **Node reference (ONE shape).**
   `[fileTag, kind, pos, end, oFileTag, oKind, oPos, oEnd]` — the
   first four identify the node when it is parse-tree; for a
   synthetic node they are `[-1,-1,-1,-1]` and the o* four carry
   the getParseTreeNode original's reference (its own fileTag);
   all-sentinel o* = the frozen synthetic-without-original class.
4. **Symbol reference (ONE shape).**
   `[escapedName, declCount, [nodeRef × min(declCount, 8)]]` —
   escapedName VERBATIM (schema-2 retires v1's slash-stripping for
   this field; the mint validator instead rejects any recorded
   string containing a MACHINE-SPECIFIC root — the workspace path,
   its realpath, or the observing process cwd. Canonical VIRTUAL
   overlay roots such as `/.src` are legitimate recorded content:
   external-module symbols are NAMED by their virtual path, so
   errorModuleName/escapedName must carry them. Clarified at the E3
   mint 2026-08-31 — hygiene targets machine paths, never canonical
   names). Mint-side validation:
   the ≤8-declaration prefix must uniquely identify one symbol of
   the recorded program, else the event is mint-classified
   `ambiguous-symbol`; declCount=0 is the frozen
   `zero-declaration-symbol` class (both fail-closed classes with

5. **Sites.** The 20 v1 resolver sites re-encoded, plus SEVEN new:
