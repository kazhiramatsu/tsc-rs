  defer an applicable case to its named later slice; it remains in the census.

## 4. Lane semantics — W-H2.6C study contract

W-H2.6C follows W-H2.6B: pinned TypeScript 6.0.3, fresh processes, two
observations per case, exact capture, and no hand-authored expected bytes.
It runs in m-1, not during this authoring pass; family/case totals are
TO-VERIFY(m-1).

| lane | W-H2.6C must confirm | W-H2.6C must falsify |
| --- | --- | --- |
| external sourceMap | .js.map bytes, URL comment, map record, callback metadata, emitResult.sourceMaps, emitted files, and map-then-js order agree exactly | any missing/extra map, URL, payload, record, metadata, path, byte, or order |
| inlineSourceMap | the data URI decodes to the exact map string; result records and sourceMapUrlPos agree; no .js.map write occurs | non-exact payload, absent/misaligned record, wrong position, or any map write |
| inlineSources | exact registered source text and source ordering appear under both external and inline map modes, including zero-mapping sources | missing/wrong content, ordering drift, or a changed null/absent arm |
| sourceRoot | normalization, trailing separator, map field, and sources[] relativization match upstream | wrong field, slash, common-directory choice, or source identity |
| mapRoot | relative/rooted URL arms, per-file nesting, encoding, and artifact location match; the root does not relocate the artifact | wrong URL arm, nesting, escaping, artifact path, or map record |
| source-map record/metadata | every applicable case reports the same map presence, result entry, callback data, write set/order, diagnostics, and emitSkipped | any facet is omitted, normalized, inferred from JS, or differs between repeated observations |
| composition/fault/control | target/module/transform combinations, option conflicts, no-map controls, and sanctioned sink faults preserve upstream precedence | any diagnostic, partial-write, result, fault, or transform-composition precedence differs |

The study freezes lane semantics only after each rule is recorded. A failed
confirmation becomes a named owner/facet for m-2, not a weakened projection.
