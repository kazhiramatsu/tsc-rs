# H2.7e m-7: Bundle declaration map paths and artifacts

The declaration map input and artifact workers now accept a Bundle separately
from a single SourceFile. A Bundle supplies no sourceFile to the map-root
directory or URL calculation. Its callback sourceFiles list is the entire
emitted Bundle list; the sourceMaps observation still comes from the recorder's
raw source registrations. These lists can differ in order and must not be
substituted for one another. Empty callback lists remain present empty lists.

The shared path change was proposed as
`target/h2-7e-bundle-execute-paths.patch` and committed by the parent as
322a5bf3. Its existing public single-source functions retain their signatures
and delegate with Some(source). Narrow crate-private workers take an optional
source and skip per-file mapRoot nesting for None. No request validator or
public outFile route changes in this packet.

`declaration_bundle_map_recording_inputs_for` applies the existing declaration
option projection: declarationMap becomes sourceMap, sourceRoot and mapRoot
survive, and both inline options are absent. `finish_declaration_bundle_map`
shares the prior single-source artifact worker, preserving complete map JSON,
map-before-text callback construction, text-only BOM, UTF-16 URL position and
declaration diagnostic metadata. The executor remains responsible for actual
write ordering, sink failure behavior, listing and blocking.

Pinned TS6 `printSourceFileOrBundle` (`_tsc.js:116744-116804`),
`getSourceMapDirectory` (`116812-116825`) and `getSourceMappingURL`
(`116826-116857`) distinguish undefined sourceFile for Bundle in exactly these
places. The fixed native source 1f70213d4922b434345f639b441681e470c7cfc1,
`tsc/internal/compiler/emitter.go:417-482`, retains the same nil-source path
branches. Its single-source printer and write-result model are an architecture
reference, not a replacement for the TS6 callback contract.

The new observer freezes ten complete ordinary TS Program.emit tuples twice:
default, relative/URL sourceRoot, relative/absolute/URL mapRoot, both roots,
inlineSources, inlineSourceMap and a relative Unicode output with CRLF/BOM.
The Rust path replay reuses the existing H2.6b mapping decoder. It supplies TS
registration/position observations to the shared generator and compares exact
map JSON and URL from the real Bundle option/path workers. It checks UTF-16
comment offsets without treating them as byte offsets. This is a path/options
facet: it does not prove the Bundle printer's mapping positions or registration
order. Complete callbacks and Program diagnostics remain in the fixture for
later composition checks. No sourceRoot/mapRoot owner boundary is lifted.

The D recording packet owns actual Bundle print-position and registration
comparison. Its twelve unchanged/new inputs include the three original D/E
compound cases, and will use this artifact worker for complete callback byte,
BOM, source association and metadata comparison. Ordinary-versus-forced parse
emit metadata lifetime remains a separate runtime producer, never a hardcoded
map correction. Global profiles, canaries, schema and adoption remain with the
parent integration task.

The worktree-exclusive `target/h2-7e-api-check` validation uses one Cargo job
and test thread at background priority. All 19 source-map library tests pass,
including the new ten-case Bundle path replay and existing H2.6b single-source
lane replay. All 24 prior direct nonbundle declaration-map cases also pass
through the shared finisher. The new observer's freshness check reproduces
all ten complete observations twice. Emitter library and test-target clippy
pass with warnings denied; formatting and diff checks pass. This is the
bounded worker/path packet. D's actual Bundle recorder/artifact composition
and the parent's public runtime/command integration remain separate checks.
