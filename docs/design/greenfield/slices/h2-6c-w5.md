## 1. Pool identity and the census instrument

The W5 pool is the FROZEN 202-row non-refused manifest set: 193 rows
with `writes_diverging > 0` (1,191 positional write divergences) and 9
diagnostics-bearing rows without write divergence.

The ratchet counter (`count_diverging_writes`,
h2_2c_acceptance.rs:2382) is POSITIONAL: it zips expected and actual
write sequences in order and adds the length difference, and the
`_with_data` wrapper (:2779) adds up to one more per pair on callback
metadata deltas. A single missing `.d.ts` write mid-sequence therefore
shifts every later pair and inflates the row's count. This semantic is
FROZEN — it is the ratchet's exact-join basis and W5 does not change
it. For truth-finding, W5 adds a PATH-JOINED census mode to the
`#[ignore]`-gated band probe
(`crates/compiler/tests/integration/source_map_band_probe.rs`,
`TSRS_H2_6C_PROBE_LIST` + `census.jsonl`): every rust write is matched
to the frozen observation write at the same path (uniqueness
asserted), yielding per-case exact/diverging/missing/rust-only sets
and reported-diagnostic deltas. The probe mirrors ALL three frozen
execution routes exactly as the acceptance prepares them
(recorded-compiler-plan and qualified-vfs on the complete MapFamily
floor; project-mount through the hermetic mount with the acceptance's
structural-key filtering, h2_2c_acceptance.rs:3660). Per the round-1
review, the per-case DETAIL dumper is also path-joined (expected rows
in frozen order, rust-only rows appended) and renders segment tables
for every `.map`-suffixed write (`.jsx.map` included), so
declaration-absence shifts can no longer make a detail table compare
different paths. Census evidence for the full pool was minted
2026-08-31 (202/202 rows; session artifacts `w5-census/census.jsonl`,
`w5-analysis.txt`, and the per-case `w5-divdumps/` mapping tables for
all 91 byte-diverging rows).
