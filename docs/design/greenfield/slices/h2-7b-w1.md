3. **Alternative-containing-module specifier candidates** (3 rows + 3 closures). Rust selects the public re-export container upstream selects (`getModuleSpecifiers` → `tryGetModuleNameFromExportsOrImports`, the alternative containing modules), so the declaration is emitted with upstream's specifier instead of a false TS2883.
