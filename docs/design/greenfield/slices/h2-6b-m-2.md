## 4. Fixture gates (the teeth)

1. **Boundary-controls flip:** the `refusal-control` arm of the 6a emit
   contract becomes `assert_parity_case` for all five cases (the four
   valid-option shapes emit mapped/inline exactly as frozen; the bare
   `inlineSources` fault case emits UNMAPPED js exactly as frozen — its
   TS5051 is a pre-emit config diagnostic owned by conformance, not by
   the emit path). Census `(29, 5, 2)` → `(34, 0, 2)`.
2. **W-H2.6B emit gate (new, same file):** every 6b case through the
   REAL `ProgramSession::emit`:
   - flat external and inline cases → `assert_parity_case` (the write
     list itself proves the inline no-map-artifact shape);
   - the six `outDir` cases → the typed H2.8a `outDir` deferral arm
     (byte parity for them is m-1-suite-proven at the print/lane level;
     the `path-shapes` precedent verbatim);
   - the two `sink-fault` fault cases → a failing-sink wrapper (records
     the attempt, returns the error for the selected path): write
     ATTEMPTS equal the frozen write list, exactly one
     `Could_not_write_file` diagnostic carrying the failing path,
     `emitSkipped` false, and the healthy control replays as parity;
   - `fault-noemitonerror-inline` → emit refuses nothing, produces zero
     writes with `emitSkipped` (the noEmitOnError gate), matching the
     frozen observation.
3. Determinism: one representative inline case emitted twice
   byte-identically (the 6a determinism-test pattern).
