# H2.7e m-6: preserved source reference paths

The nonbundle declaration path provider previously preferred an ordinary
declaration output, then JavaScript output, then the original source. That
projection differs from pinned TypeScript 6.0.3 `getReferencedFiles`
(`_tsc.js:114580-114610`), which requests `getOutputPathsFor(file, host, true)`.
The forced path always includes a declaration output, independently of whether
declarations or the referenced source's own emit are enabled. Input declaration
files retain their original path through the declaration root's earlier branch.

The fixed native source at `1f70213d4922b434345f639b441681e470c7cfc1`,
`tsc/internal/transformers/declarations/transform.go:464-497`, makes the same
forced request. The runtime fix reuses the existing production
`declaration_output_path` calculation for every known source reference target.
It does not change selection, emit blocking, common-source-directory policy,
output planning or request admission.

`observe-declaration-reference-paths.mjs` records the complete declaration,
declarationMap and Program-inclusion matrix: eight programs, each with seven
same-checker calls, each sequence repeated from a fresh Program twice. Only
main.ts is a root; the referenced file stays mounted when noResolve excludes
it from the Program. A fresh forced whole-Program call precedes whole and
target getters, followed by forced target, ordinary command, getter and forced
whole-Program calls. The final Program diagnostic snapshot comes afterward.

The first production comparison passed seven of eight base rows. With
declaration:false, declarationMap:false and an included source, Rust printed
`dep/b.js` where TypeScript printed `dep/b.d.ts`. Excluded sources produced no
preserved reference. Two supplementary rows independently reproduced the same
cause: JSON required `dep/data.d.json.ts` instead of `dep/data.json`, and a JS
source suppressed by noEmitForJsFiles required `dep/b.d.ts` instead of `dep/b.js`.
The third supplementary row, an input .d.ts reference, already matched.

The first exploratory matrix also supplied outDir:"out". The existing H2.8a
request guard rejected all eight before transformation; this packet retains

Program source order and actual reference spellings, and records byte lengths
and complete callback/result shapes. The original map API and forced/getter fixtures are
unchanged. TypeScript Debug Failure in declaration-disabled map calls remains
